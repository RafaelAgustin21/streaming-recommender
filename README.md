# Sistema de recomendación de contenido mediante grafos

Proyecto del curso Complejidad Algorítmica.

## Dataset

Se utiliza MovieLens 100K, publicado por GroupLens Research.

El dataset debe descargarse desde:
https://grouplens.org/datasets/movielens/100k/

Descomprimir el contenido dentro de:

data/raw/ml-100k/

## Tecnologías

- Python
- Pandas
- NetworkX
- Matplotlib

## Algoritmo principal

Búsqueda en Anchura (BFS) sobre un grafo bipartito usuario-película.
